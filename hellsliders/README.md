# HELLSLIDERS

[Download 2.2.1 for HellForge](https://github.com/RojoMojo666/HellForge-Mods/raw/refs/heads/main/downloads/HELLSLIDERS-HellForge-v2.2.1-build25480438.zip)

Slide farther, tune how quickly you pick up speed, and set how long slides last on flat ground, uphill, and downhill. Pick a preset or dial in the controls yourself.

![HELLSLIDERS HellForge cover](../artwork/hellsliders-cover.jpg)

## Presets

**Tribes** is built around picking up speed downhill and carrying it across flat ground. **Oxygenator** keeps the faster slide and gives it more time to carry on flat ground.

Oxygenator is available in the regular preset list in **2.2.1**. You can select it with **De-restricted** turned off. It keeps the same slide tuning as before.

Open **Esc → Mods → HELLSLIDERS**, pick a preset or adjust the sliders, then select **Apply**. Some changes need a fresh spawn.

## Requirements

Enable [Bingus Shared Loader v20](https://github.com/CowboyBingus/BingusSharedLoader/releases/tag/v20) and [Mod Options Menu v1.0.1](https://github.com/CowboyBingus/ModOptionsMenu/releases/tag/v1.0.1) in HellForge.
