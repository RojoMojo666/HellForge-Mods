# P-92 Warrant — Per Player

[Download 1.0.0 for HellForge](https://github.com/RojoMojo666/HellForge-Mods/raw/refs/heads/main/downloads/P-92-Warrant-Per-Player-v1.0.0-build25480438.zip)

The P-92 Warrant gets a **12-round magazine**, **140 standard / 60 durable damage**, and **AP 4 / 4 / 3 / 1** for direct, slight-angle, large-angle, and extreme-angle hits. It keeps the stock lock-on, projectile, and single ammo feed.

## Requirements

Use HellForge 0.5 beta on game build `25480438` with synced ownership of the P-92 Warrant. This is a **Per Player** stats mod. Other players can keep their own mod setup.

Import the ZIP through **Mods → Add mods** and enable **P-92 Warrant - Per Player**. If you previously installed the **Warrant 12/12 Mini-WASP Round Test**, disable or remove it. Equip the regular **P-92 Warrant** in a fresh session. To uninstall, remove the mod in HellForge and restart the session.
