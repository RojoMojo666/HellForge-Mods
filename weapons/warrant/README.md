# P-92 Warrant Mini-WASP — Per Player

[Download 1.1.0 for HellForge](https://github.com/RojoMojo666/HellForge-Mods/raw/refs/heads/main/downloads/P-92-Warrant-Mini-WASP-Per-Player-v1.1.0-build25480438.zip)

The regular P-92 Warrant gets one 12-round magazine of guided Mini-WASP-style rounds. It keeps its native lock-on and uses the Warrant's existing missile and projectile types.

| Setting | Value |
| --- | --- |
| Direct damage | 140 standard / 110 durable |
| Direct penetration | 4 / 4 / 4 / 3 |
| Configured missile speed | 300 m/s |
| Impact payload | Stock PLAS-101 Purifier blast |
| Blast damage | 300 standard / 300 durable |
| Blast penetration | 3 / 3 / 3 / 0 |
| Outer blast radius | 3 m |

The 3 m stock blast is 0.5 m wider than the earlier prototype's custom blast. HellForge accepts the payload and the other edits as Per Player. Detonation against locked and unlocked targets and co-op connection stability still need an in-mission check.

## Requirements

Use HellForge 0.5 beta on game build `25480438` with synced ownership of the P-92 Warrant. Other players can keep their own mod setup.

Import the ZIP through **Mods → Add mods**. It updates version 1.0.0. If you previously installed the separate **Warrant 12/12 Mini-WASP Round Test**, disable or remove it. Enable **P-92 Warrant Mini-WASP - Per Player** and equip the regular **P-92 Warrant** in a fresh session. To uninstall, remove the mod in HellForge and restart the session.
